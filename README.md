# Snake Game

A focused arcade-style **Snake Game** built with HTML, CSS, and vanilla JavaScript. Control the snake using arrow keys, WASD, or the on-screen direction pad, eat the light to grow, and avoid running into walls or yourself.

## Features
- Classic snake gameplay
- Score counter
- 20x20 grid game board
- Restart control and game-over state
- Responsive layout for desktop and mobile
- Local sign-in and create-account flow
- Per-account personal best saved in browser storage

## How to Play
1. Open `index.html` in your browser.
2. Optionally choose **Sign in** to create a local arcade profile.
3. Use **arrow keys**, **WASD**, or the direction pad to move the snake.
4. Eat the light to increase your score and grow the snake.
4. Avoid hitting walls or yourself.

## Technologies Used
- HTML
- CSS (Grid Layout)
- Vanilla JavaScript (game logic and local account state)

## Optional Enhancements
Accounts are browser-local rather than connected to a server. Clearing site data removes the saved profile and best score.
